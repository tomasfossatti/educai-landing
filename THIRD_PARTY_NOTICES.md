# Third-party UI source notes

Educai includes interaction patterns adapted from **ObsidianUI**, an open-source React component collection distributed under the MIT License.

- Project: https://www.obsidianui.dev/
- Source: https://gitlab.com/Atharvsinh-codez/ObsidianUI
- License: MIT

Adapted patterns include Arrow Fill Button, Jelly Loader, Magnet Tabs, OTP-style segmented input, Dotted Grid, Spotlight-style navigation, scroll indicator, and text reveal interactions. The implementations in Educai have been modified for the product's visual identity, accessibility requirements, responsive behavior, and application flows.
